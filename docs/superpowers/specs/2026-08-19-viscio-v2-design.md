# Viscio v2 设计文档（用户实测反馈驱动）

日期：2026-08-19
状态：范围已与用户确认（2026-08-19 对话），分两批交付
前置：v1（Plans 1-3）已全部完成并验证，含 Plotly 三维图端到端演示与离线导出 data:URI 超限 bug 的修复（commit 21491c2）

## 背景

v1 部署后用户实测提出五条反馈，全部采纳。另外演示中确认了 Plotly 工作流可用：
用户 Python 代码 `fig.write_html("x.html")` → 编辑器「嵌入」上传 → 编辑/放映/离线导出三处均可交互旋转。

## 批次 A（先交付，UI 给用户过目后再定稿）

1. **UI 全面重做**——参考 Quarto 的干净学术风：白底、蓝 accent（cosmo 系）、统一间距、
   顶部标题栏（可编辑的 deck 标题 + 分享/版本历史/导出/放映动作区）+ 第二行工具栏。
   DeckList 和 Login 页一并重做。深色模式保留。
2. **工具栏 PPT 式重组**——「形状 ▾」下拉（矩形/椭圆/菱形/箭头/自由画笔），「文本框」独立按钮，
   「插入 ▾」下拉（图片/嵌入/公式/代码），「对齐 ▾」下拉（左/水平居中/右/顶/垂直居中/底），
   「图层 ▾」下拉（置顶/上移/下移/置底），编组/解组，撤销/重做，右侧缩放控件+保存状态。
3. **多选对齐**——新能力（v1 砍掉的按钮式对齐按用户要求恢复）。以"单元"为粒度：
   一个编组算一个单元整体移动，散元素各自为单元；少于两个单元时禁用。
4. **手动缩放**——适应窗口（默认）/ ± 按钮 / Ctrl+滚轮；手动缩放时画布可滚动平移。
   技术点：CanvasHandle 的参照矩形从 viewport 改为 surface 自身（缩放/滚动/居中后两者不再重合）。
5. **放映入口 + 滚动阅读模式**——编辑器头部显眼的「▶ 放映」按钮（新标签打开分享播放页）；
   播放页新增 滚动/放映 模式切换（`?mode=scroll`），滚动模式整份幻灯片竖排连续阅读。
   已知取舍：滚动模式所有页同时挂载，多个 Plotly 嵌入会同时吃内存——20-30 页、2-3 个嵌入的规模没问题。

## 批次 B（思维导图式非线性导航）

用户原话确认的形态：**自由连线、2D、不一定线性，可表达总分/树叉关系**（类幕布/思维导图）。

- 每页可起**小标题**（slides 表加 `title` 列）。
- 每 deck 一个**地图视图**：每页显示为 缩略图+标题 的节点，自由拖动摆放
  （slides 表加 `map_x`/`map_y` 列，NULL = 未摆放过，首次进入按网格自动布点）。
- **自由连线**：节点间手动画边（新表 `map_edges(id, deck_id, from_slide_id, to_slide_id)`，
  级联删除），可删除；渲染为 SVG 曲线。不做箭头方向语义之外的花样。
- 编辑器里点节点 → 跳到该页编辑；地图里拖动节点到另一节点前后可**改播放顺序**
  （更新 position）。
- **放映时跳转**：按 `M`（或 Esc 菜单）呼出地图浮层，点节点直接跳到那页；
  地图浮层也显示当前所在节点高亮。
- 缩略图实现：地图视图一次性拉全 deck 元素（复用 play 数据形态，新增
  `GET /api/decks/:id/full`），每节点用 transform:scale 渲染只读 mini Canvas；
  嵌入元素在缩略图里降级为灰色占位块（不真实例化 iframe，20-30 个 Plotly 同时挂载会炸内存）。

## 明确不做

- 3D 地图/无限画布性能优化（30 页规模用不上）
- 连线上的文字标注
- 演讲者双屏视图（维持 v1 的每页备注）
